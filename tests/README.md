# 测试脚本

| 脚本 | 用途 | 运行 |
|---|---|---|
| `test_accuracy.py` | **精度压力测试**：8 类广告正样本（拼图+QR / 长条 / 中央透明水印 / 角落小水印 / 深底白字 / 模糊小字）+ 6 类干扰负样本（普通风景 / 正常文字菜单 / 版权水印 / 图表 / 纯色壁纸 / 手机截图），统计召回率与误报率 | `python tests/test_accuracy.py` |
| `test_e2e.py` | **端到端功能流程**：启动空状态 → 添加文件夹 → 扫描（暂停/继续/当前文件/进度打勾）→ 筛选 → 勾选链（Ctrl+A toggle/反选/点圈）→ Lightbox（入场/缩放/Esc）→ 标记保留 → 隔离处置 → 恢复 → 二次扫描缓存 → 改规则缓存失效 → 主题切换 → 移除文件夹 → 关闭 | `python tests/test_e2e.py` |

两者都需要 GUI 环境（Windows 桌面会话）。工程内置的自测命令：

```bash
python ad_filter.py --selftest    # 引擎判定回归（含真实样本，可选）
python ad_filter.py --gui-test    # GUI 功能自测（76 项）
```

**基线**（2026-10-20）：精度 召回 22/22 (100%)、误报 0/22；E2E 37/37；gui-test 76/76。
