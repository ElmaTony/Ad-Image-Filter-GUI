# tests/ —— 测试套件

## 分层与运行方式

| 层级 | 命令 | 断言数 | 能否开箱即跑 |
|---|---|---|---|
| 引擎自测 | `python ad_filter.py --selftest`（项目根） | 引擎全流程回归 | ✅ 合成 fixture |
| GUI 功能自测 | `python ad_filter.py --gui-test`（项目根） | 131 项 | ✅ 合成 fixture，临时隔离区 |
| 工作台回归 | `python tests/test_workbench.py` | 9 用例 | ✅ 临时图片与配置 |
| UI 元素审查 | `python tests/audit_ui.py` | 72 项 | ✅ 深浅主题、三个尺寸、合成图片 |
| 端到端 | `python tests/test_e2e.py` | 37 项 | ⚠️ 需要本地真实样本 |
| 精度压力测试 | `python tests/test_accuracy.py` | 22 正样本、22 负样本 | ✅ 全部自动生成 |

在项目根目录运行。GUI 自动化可设置 `QT_QPA_PLATFORM=offscreen`，无需弹出窗口。离屏平台会显式注册本机中文字体用于截图。文件操作与用户配置全部使用测试临时目录。

## 需要真实样本的用例

`test_e2e.py` 需要 `testdata/real4_*` 与 `real6_*` 真实广告样本（个人数据，**不随仓库分发**，被 `.gitignore` 排除）。精度测试不依赖这些真实图片。换机器时：

- 没有样本：E2E 会明确报缺失，其余合成测试不受影响
- 有样本：把广告图放进 `testdata/`，文件名以 `real` 开头即可被自动纳入（如 `real4_*.jpg`、`real6_*.png`）
- 合成样本兜底：`python ad_filter.py --make-fixtures` 可重新生成 `type1/type2/normal_*` 等合成图（覆盖大部分精度用例）

## 测试覆盖内容速览

- **test_e2e.py**：启动空状态 → 添加文件夹 → 扫描（暂停/继续/当前文件/进度打勾）→ 筛选 → 勾选链（Ctrl+A toggle/反选/点圈）→ Lightbox（入场/缩放/Esc）→ 标记保留 → 隔离处置 → 恢复 → 二次扫描缓存 → 改规则缓存失效 → 主题切换 → 移除文件夹 → 关闭
- **test_accuracy.py**：6 类广告正样本（拼图+QR / 长条 / 中央透明水印 / 角落小水印 / 深底白字 / 模糊小字）+ 6 类干扰负样本（普通风景 / 正常文字菜单 / 版权水印 / 图表 / 纯色壁纸 / 手机截图），统计召回率与误报率
- **test_workbench.py**：独立异常筛选、大小写搜索、跨筛选全选、隐藏项确认、隔离撤销、删除范围、导入控件同步、完整 OCR、焦点保持、任务禁用态、多文件夹与小窗口。
- **audit_ui.py**：标题栏按钮几何、顶栏/筛选条高度、网格单元尺寸、无侧栏断言、底部停靠完整性、像素级语义色（执行处置=红、品牌橙在场）
- **preview_layouts.py**：开发期布局预览截图工具（渲染当前界面到 `_preview/`，非断言测试）

**基线**（2026-10-30）：精度召回 22/22、误报 0/22；E2E 37/37；GUI 131/131；工作台 9/9；UI 72/72。
