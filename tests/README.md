# tests/ —— 测试套件

## 分层与运行方式

| 层级 | 命令 | 断言数 | 能否开箱即跑 |
|---|---|---|---|
| 引擎自测 | `python ad_filter.py --selftest`（项目根） | 引擎全流程回归 | ✅ 合成 fixture |
| GUI 功能自测 | `python ad_filter.py --gui-test`（项目根） | 126 项 | ✅ 真实窗口平台，合成 fixture |
| UI 元素审查 | `python tests/audit_ui.py` | 48 项 | ✅ 几何/颜色断言，深浅主题各一遍 |
| 端到端 | `python tests/test_e2e.py` | 37 项 | ⚠️ 需要本地真实样本 |
| 精度压力测试 | `python tests/test_accuracy.py` | 召回/误报统计 | ⚠️ 需要本地真实样本 |

均需要 Windows 桌面会话（真实窗口平台），在**项目根目录**下运行。

## 需要真实样本的用例

`test_e2e.py` 与 `test_accuracy.py` 会读取 `testdata/real*` 下的真实广告样本（个人数据，**不随仓库分发**，被 `.gitignore` 排除）。换机器时：

- 没有样本：这两个测试会在样本缺失处报错/跳过，其余测试不受影响
- 有样本：把广告图放进 `testdata/`，文件名以 `real` 开头即可被自动纳入（如 `real4_*.jpg`、`real6_*.png`）
- 合成样本兜底：`python ad_filter.py --make-fixtures` 可重新生成 `type1/type2/normal_*` 等合成图（覆盖大部分精度用例）

## 测试覆盖内容速览

- **test_e2e.py**：启动空状态 → 添加文件夹 → 扫描（暂停/继续/当前文件/进度打勾）→ 筛选 → 勾选链（Ctrl+A toggle/反选/点圈）→ Lightbox（入场/缩放/Esc）→ 标记保留 → 隔离处置 → 恢复 → 二次扫描缓存 → 改规则缓存失效 → 主题切换 → 移除文件夹 → 关闭
- **test_accuracy.py**：8 类广告正样本（拼图+QR / 长条 / 中央透明水印 / 角落小水印 / 深底白字 / 模糊小字）+ 6 类干扰负样本（普通风景 / 正常文字菜单 / 版权水印 / 图表 / 纯色壁纸 / 手机截图），统计召回率与误报率
- **audit_ui.py**：标题栏按钮几何、顶栏/筛选条高度、网格单元尺寸、无侧栏断言、底部停靠完整性、像素级语义色（执行处置=红、品牌橙在场）
- **preview_layouts.py**：开发期布局预览截图工具（渲染当前界面到 `_preview/`，非断言测试）

**基线**（2026-10-24）：精度 召回 22/22 (100%)、误报 0/22；E2E 37/37；gui-test 126/126；audit 48/48。
