## 已修复的问题

| 范围 | 原问题 | 处理与验证 |
|---|---|---|
| 大图查看 | 按整窗适配图片，上下工具栏覆盖图像 | 独立图片视口；适配、裁剪、缩放锚点和平移边界使用同一区域；横、竖、方图四条边缘像素验证 |
| 大图交互 | 图片加载失败时滚轮访问空图对象；信息栏与翻页热区混用 | 缺图保护；翻页限定图片区高度；F 隐藏全部工具并停用隐藏箭头热区 |
| OCR 重复推理 | 小图的条带和全图兜底是同一图，重复跑相同的推理 | 单图内复用成功结果，仍按旧顺序累积文本和匹配正则，避免改变跨段匹配语义 |
| 提亮预处理 | 同一区域为门控与二值化重复转换 HSV | 区域内复用 HSV 和二值掩码，门控阈值与形态学处理保持不变 |
| 并行任务 | 每批等待最慢图片，其他线程空闲；列表头删除反复移动剩余项 | 有界动态补充，最多保留用户配置允许的在途任务；确定性慢任务测试验证补充不被阻塞 |
| 取消与异常 | 取消通知可能先于后台任务结束；初始化失败不发结束状态 | 在途任务结束后发取消通知；初始化/扫描异常发送独立错误事件，界面恢复可用 |
| OCR 异常 | 推理异常被当成无文字，可能缓存为正常图片 | 显示为异常图片；异常结果不作为缓存命中，再扫可以重试 |
| OCR 并发 | RapidOCR detector 每次调用改写共享 preprocess_op | 每线程浅拷贝可变外壳，继续共享 ONNX 会话与模型；并发状态隔离测试 |
| 相似指纹 | 无符号 64 位值超过 SQLite 有符号整数上限 | 存储时转换为有符号值，读取时恢复 64 位；最高位和全 1 指纹回归 |
| 缓存失效 | 修改相似阈值清空全部 OCR 结果 | 识别配置签名排除独立的聚类设置；保留按图片属性校验的指纹缓存 |
| 文件隔离/恢复 | 用秒级时间后缀避让，连续同名操作仍可能覆盖 | 逐项查找未占用名称；多次隔离/还原验证所有原字节保留 |
| 隔离清单 | 读取损坏清单后重置为空；直接覆盖写可能留下半份文件 | 校验既有清单并拒绝破坏性覆盖；原子替换，逐张保存隔离记录；保存失败移回文件并报告错误 |
| 审查焦点 | 保留中间图片后焦点回到前面；过期相似组包含已移除路径 | 保持相邻索引，过滤分组中的失效成员 |
| 缩略图 | 重扫同一路径仍显示旧图，曾失败的路径不再尝试 | 重扫清理缓存与失败标记，按扫描代次忽略过期后台结果 |
| 规则编辑 | 测试器把低分命中显示为正常；无穷权重可抛出未捕获异常 | 测试器与扫描一样将低分命中记疑似；拒绝不可转换权重 |
| 隔离区窗口 | 新配置目录尚未生成时先弹出文件夹选择，无法直接管理旧位置 | 直接显示管理窗口，空目录与旧位置切换沿用同一入口 |
| 测试环境 | 旧预览脚本会读写真实配置并将测试扫描加入历史 | 重写为临时合成图片；smoke、自测缓存和精度测试路径隔离 |
| 公共组件/弹窗 | 部分备用组件颜色令牌引用错误，保存动作可能重复发接受信号 | 修正令牌引用，确认按钮避免重复接受 |
| 发布 | 中文附件名可能被服务器规范化，附件未核对即公开 | 固定 ASCII 附件名，草稿上传，核对附件完整性后公开，不生成重复 EXE |

## 精度与速度对照

基线为 `24389df`。对照使用同一套模型、CPU 设置和扫描参数：12 张合成图与本机 7 张只读样本，共 19 张。对每张图片比较 path、verdict、score、reasons 和 ocr_text。新旧版串行和并行结果均一致。

| 路径 | 旧版 | 新版 | 比值 |
|---|---:|---:|---:|
| 串行 | 7.803 s | 5.284 s | 1.477× |
| 4 线程扫描 | 3.678 s | 2.540 s | 1.448× |

OCR 调用从 56 次减到 44 次。以上为模型预热后本机一次对照，不是所有目录的速度承诺。原始汇总见 `scan-benchmark-2026-11-09.json`；报告不包含私有图片路径、文本或图像。

完整合成精度集覆盖 22 张正样本和 22 张负样本：正样本全部命中，负样本没有误报。图片缩放尺寸、OCR 模型、识别阈值、QR 通道、条带/全图范围及形态学步骤均未为提速而缩减。原有近纯色跳过与提亮门控沿用既有策略，本次未增加新的启发式跳过。

## 后续可提升的方向

- 超大原图的完整解码仍在大图窗口打开时进行，可增加异步加载和按需原始像素查看，改善打开延迟及内存占用。此项不涉及扫描降采样策略。
- 非法手工编辑配置的字段校验还可集中化；现有导入窗口已校验常见格式，但不以此次回归替代任意损坏 JSON 的容错验证。
- 多程序实例同时修改同一个隔离区仍需要跨进程锁。当前单实例界面会互斥文件操作，本次测试验证的是该工作方式。
- GPU 和更改检测分辨率可能影响性能或识别结果，未纳入本次提速；今后需要独立精度集及实际目录对照后再决定。
