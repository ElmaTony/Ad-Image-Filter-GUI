# 2026-11-14 审查修复与验证

开发验收记录；发行说明另行提供，只包含用户可感知的变化。基线为 `80c3de3`。

## 缺陷修复

1. 隔离条目的文件路径必须位于所选隔离区内，规范化后再次验证；拒绝目录穿越和指向外部的符号链接。新清单记录相对位置，复制或移动后只操作新位置。旧版越界清单停止操作并明确说明原因。
2. 隔离、还原和删除使用按目录的线程锁和系统文件锁，锁覆盖读取清单、选择目标、文件移动与保存。两个独立进程的回归保留全部 30 条记录。
3. 删除灰度标准差门控，只有 RGB 每个通道都完全均匀才跳过像素识别。白底稀疏链接使用真实 OCR 验证能够进入疑似/广告结果。
4. 缓存每条结果附识别配置签名，包括实际使用的识别开关和引擎结果版本。单图及批量读取均验证签名，不依赖另一个实例写入的全局元数据。
5. 启动和导入共用配置校验与类型规范化；校验布尔值、有限数值、整数参数、范围、规则和目录列表。先成功保存导入结果，再更新运行中的配置。损坏的启动配置整体回退默认值。
6. 根目录消失、无法访问或遍历失败发送扫描错误，不记录为成功的零图片扫描。
7. 缩略图、详情和大图均按 EXIF 方向显示；识别通道仍使用原有像素加载流程，避免借显示修复改变识别输入。

## 性能与界面

- 相似分组将 64 位指纹分成阈值加一段，通过必有一段一致的性质缩小候选范围，再按原代表顺序验证完整汉明距离。高阈值保留线性方法；随机、相同、近似和多个代表均可匹配的用例与原贪心算法完全一致。
- 大图和详情使用有界后台加载器，两个在途解码、一个待处理请求，按代次丢弃过期结果。大图先显示预览，放大需要更多像素时异步加载完整原图，保持缩放和平移状态。
- 批量隔离在每次移动前持久化恢复意图，只在批次前后写完整快照。中断后可重放日志；快照写入失败仍保留日志。跨盘复制中断且状态不明确时停止操作并保留两端文件，要求检查，不擅自删除。
- 界面队列每次处理最多 5,000 条或 12ms，识别类别计数增量更新，未勾选时跳过全表选择统计。扫描需等到结束事件处理完成才重新开放扫描和文件处置，防止剩余队列混入下一轮。
